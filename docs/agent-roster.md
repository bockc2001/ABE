# Agent Roster — ABE Template

## Naming Convention

All non-EA agents use **short American names** where the **first letter matches the role's initial**. EA agents use short American names matching the **first letter of their human counterpart's name**.

## Human-Agent Pairings

| Human | Title | Counterpart Agents | EA |
|---|---|---|---|
| [Primary Leader] | CEO | CoS, CSO — direct; all others via roll-up | [Name] |

> Only CoS and CSO have direct human-counterpart pairings in the agent reporting structure. All other agents reach the CEO via their reporting chain roll-up. EAs are not part of this model — they serve humans directly and have no agent reporting relationship.
